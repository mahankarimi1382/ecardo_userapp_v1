# قوانین اجرای مشترک

1. Checkout واقعی را استفاده کن؛ این بسته جایگزین سورس برنامه نیست.
2. اول `python -m graphify query ...` مطابق دستور پروژه، بعد کاوش وسیع سورس.
3. `git checkout`, `git stash`, `git reset --hard`, `git clean`, حذف تغییرات دیگران ممنوع.
4. baseline را با دستورهای فقط‌خواندنی بگیر. `git fetch` لازم نیست و در مرحلهٔ اول اجرا نشود.
5. فایل‌های locked/shared و بخش‌های متعلق به ایجنت دیگر را تغییر نده.
6. هیچ `flutter test` را توسط ایجنت‌های موازی اجرا نکن؛ این فاز اصلاً تست اجرا نمی‌کند.
7. هیچ live payment، transfer، card issuance، release، deploy یا webhook تحریک‌شده‌ای انجام نده.
8. از دادهٔ حساس در log/CSV/اسکرین‌شات اجتناب کن. شواهد مالی باید با sandbox/تست و ماسک‌کردن PII ساخته شوند.
9. اگر ابزار/فایل/مجوز در محیط موجود نیست، `BLOCKED` و دلیل بنویس؛ فرض نکن موجود است.
10. هر تغییر مجاز در این مرحله باید مستندات جدید باشد؛ بازنویسی سورس اپ یا فایل‌های موجود مجاز نیست.
