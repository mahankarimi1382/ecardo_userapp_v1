# eCardo Resilience Review Pack

این بسته بر اساس گزارش اخیر دربارهٔ Exchange، Passcode و صدور کارت تهیه شده است.

فایل‌ها:
- `01_REVIEW_AND_REMAINING_RISKS_FA.md` — بررسی فنی ادعاها، ریسک‌های باقی‌مانده و معیارهای طراحی
- `02_REGRESSION_TEST_MATRIX_FA.md` — ماتریس تست رگرسیون با شناسه و معیار پذیرش
- `03_AGENT_PROMPT_FA.md` — پرامپت قابل استفاده برای ایجنت اصلی

محدودیت: این بسته تغییر سورس اپ یا بک‌اند نیست و ادعا نمی‌کند اصلاحات گزارش‌شده را اجرا کرده است. برای تأیید واقعی، فایل‌های checkout محلی و شواهد backend staging لازم است. این بسته اجازهٔ push/deploy نمی‌دهد.
