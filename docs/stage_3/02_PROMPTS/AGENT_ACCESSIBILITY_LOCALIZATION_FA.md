# عامل D — Accessibility / RTL / i18n

تمام Route IDهای اختصاص‌یافته را از نظر Semantics، focus order، hit targets، contrast، text scaling، long strings، RTL/LTR، keyboard inset، date/number/currency formatting و Reduce Motion بررسی کن. literalهای قابل ترجمه را شناسایی و به روش localization موجود پروژه متصل کن. زبان جدید یا پکیج تازه بدون ضرورت و ADR اضافه نکن. هر ادعا را به route و evidence متصل کن.
