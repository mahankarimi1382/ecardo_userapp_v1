# عامل F — Navigation and Screen State

ناوبری route، back, nested navigation، bottom sheets، dialogs، deep links (اگر وجود دارد)، auth guards و نتیجهٔ بازگشت را در Route Catalog تطبیق بده. برای هر صفحه stateهای loading/empty/error/offline/pending/disabled را تعیین کن و از نمایش state متناقض بین صفحه/receipt/history جلوگیری کن. تنها بر اساس رفتار سورس/اجرای واقعی نتیجه‌گیری کن.
