# Definition of Done برای هر صفحه

یک صفحه فقط وقتی DONE است که:
1. شناسه‌اش به Route Catalog واقعی وصل است.
2. Screen Spec و business contract مربوط معلوم‌اند.
3. طراحی از design system موجود استفاده می‌کند یا استثنا ثبت شده.
4. stateهای relevant پوشش دارند و N/A دلیل دارد.
5. CTAهای اصلی عمل واقعی دارند یا disabled reason مشخص.
6. مبلغ/status/receipt و مجوزها authoritative هستند.
7. RTL/LTR، locale، text scale و keyboard بررسی شده‌اند.
8. screenshot قبل/بعد بدون PII ثبت شده.
9. تست مربوطه نتیجهٔ واقعی دارد؛ status تکمیل بدون evidence ممنوع.
10. issueها، blockerها، owner و handoff ثبت شده‌اند.
