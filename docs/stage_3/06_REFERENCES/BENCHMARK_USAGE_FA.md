# استفاده از benchmarkهای XPay و xMoney/xPortal

این مرجع برای الهام از الگوهای محصول است، نه نسخه‌برداری بصری یا حقوقی. مواردی که می‌توان به شکل مستقل ارزیابی کرد:
- تفکیک واضح balance/account، activity و اقدام اصلی؛
- گام‌های روشن entry → review → authorize → pending/result؛
- نمایش قابل‌فهم وضعیت عملیات و امکان بازیابی امن؛
- هماهنگی wallet/card/transaction history در گردش‌های واقعی؛
- ناوبری قابل‌پیش‌بینی و متن‌های کوتاه با CTA واضح.

برای هر ایده، یک problem statement، معیار موفقیت و مقایسهٔ قبل/بعد تعریف کن. کد، دارایی، copy، layout خاص یا هویت برند تجاری را کپی نکن. بررسی لایسنس محصول یا پکیج و ADR برای وابستگی جدید الزامی است. اگر الگو با قرارداد مالی backend ناسازگار است، قرارداد مالی مقدم است.
