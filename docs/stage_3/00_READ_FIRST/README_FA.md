# بسته مرحلهٔ ۳ eCardo — ارتقای سراسری صفحات، تجربه کاربر و رفتارهای UI

## هدف
این بسته مرحلهٔ بعدی پس از «کشف اپلیکیشن» و «یکپارچه‌سازی منطق و رفع ریسک‌های بحرانی» است. هدف، ارتقای سیستماتیک تمام صفحات و مسیرهای واقعاً موجود در eCardo است؛ بدون محدودشدن به Home و چند صفحهٔ قابل‌دسترسی.

**این ZIP یک بستهٔ اجرایی برای ایجنت است، نه ادعای انجام‌شدن تغییرات روی checkout واقعی.** اجرای آن باید در محیطی انجام شود که سورس کامل، دستورهای پروژه و خروجی واقعی مراحل ۱ و ۲ در دسترس باشند.

## پیش‌نیازهای اجباری
1. از مرحلهٔ ۱: `docs/app-map/ROUTE_CATALOG.csv`، `SCREEN_SERVICE_MATRIX.csv`، `BUSINESS_FLOWS.md` و `COVERAGE_REPORT.md` (یا معادل مستندشدهٔ آن‌ها).
2. از مرحلهٔ ۲: قراردادهای تأییدشده، فهرست ریسک‌ها، تست‌ها و گزارش handoff.
3. `AGENTS.md`، `DESIGN_SYSTEM_GUIDE.md` و هر دستور یا skill محلی باید پیش از کار خوانده شوند.

اگر خروجی مرحلهٔ ۱ یا ۲ وجود ندارد، ناقص است یا با checkout فعلی اختلاف دارد، اول باید همان خلأها تکمیل شوند. **نباید با حدس، کاتالوگ واقعی صفحه ساخته شود.**

## ترتیب شروع
1. `01_ROADMAP/STAGE_3_FULL_SURFACE_UPGRADE_FA.md` را بخوان.
2. `02_PROMPTS/STAGE_3_MASTER_AGENT_PROMPT_FA.md` را به هماهنگ‌کننده بده.
3. اسکریپت `05_SCRIPTS/build_screen_upgrade_registry.py` را روی کاتالوگ واقعی Route اجرا کن.
4. رجیستری صفحات را بازبینی کن؛ کاندیدا، صفحهٔ runtime-verified و صفحهٔ ارتقایافته را با هم اشتباه نگیر.
5. بعد از تأیید خط مبنا، کار را در بچ‌های کوچک اجرا کن.

## محدودیت ایمنی و انتشار
- هیچ Push، Release یا Deploy انجام نشود.
- هیچ تراکنش، انتقال، پرداخت، صدور کارت یا عملیات برگشت‌ناپذیر واقعی برای تست اجرا نشود.
- `git checkout`، `git stash`، reset یا حذف تغییرات دیگران ممنوع است.
- فایل‌های قفل‌شدهٔ Design System و فایل‌های مشترک طبق راهنمای پروژه باید مالک مشخص داشته باشند.
- تست‌های نهایی shared-worktree را موازی اجرا نکنید؛ دستور محلی پروژه اولویت دارد.

## تعریف «تمام صفحات ارتقا یافته‌اند»
فقط وقتی پذیرفته می‌شود که تمام موارد واقعی کشف‌شده در رجیستری وضعیت داشته باشند، موارد خارج از scope دلیل مستند داشته باشند، برای وضعیت‌های ضروری شواهد تصویری و تست ثبت شده باشد و هیچ مورد P0/P1 باز بدون پذیرش رسمی ریسک باقی نمانده باشد. «کامپایل شد» یا «Home بهتر شد» معادل پوشش کامل نیست.
