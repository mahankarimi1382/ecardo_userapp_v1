# استفاده از XPay و xMoney/xPortal در این مرحله

این فاز عمدتاً فنی و یکپارچه‌سازی است. از نمونه‌های محصولی برای فهم الگوهای تجربه استفاده می‌کنیم، نه برای تعریف قوانین مالی یا کپی‌کردن کد و طراحی.

- **xMoney / xPortal:** الگوهای احتمالی برای پیوند تجربهٔ حساب، کیف پول، پرداخت و خدمات؛ هر ادعا باید با صفحهٔ رسمی/محصول دقیق تطبیق داده شود.
- **XPay (محصول تجاری Flutter):** می‌تواند برای الگوهای screen inventory و UI flow الهام بدهد؛ استفاده از کد یا asset فقط در چارچوب license مجاز.
- **Wise / Revolut و سایر محصولات:** الگوهای شفافیت هزینه، نمایش وضعیت، تاریخچه و خطاهای قابل‌فهم به‌عنوان معیار UX بررسی شوند.

قواعد مالی eCardo از قرارداد backend، مدل و تست معتبر می‌آید؛ نه از محصول رقیب، اسکرین‌شات یا نمونهٔ کد ناشناخته.
