# منابع ابزار و توسعه — با سطح اطمینان

## شناخت کد و ذخیرهٔ نقشه
- Graphify: https://github.com/Graphify-Labs/graphify — گراف قابل پرس‌وجو برای روابط کد و اسناد؛ خروجی گراف باید مرتب refresh و یافته‌های inferred از extracted متمایز شود.
- Serena: https://github.com/oraios/serena — retrieval/editing معنایی از طریق MCP و زبان‌محور.
- Repomix: https://github.com/yamadashy/repomix — بسته‌سازی کنترل‌شدهٔ repo برای زمینهٔ مدل؛ قبل از هر pack، secrets و PII exclude شوند.

## اجرای UI و integration tests
- Patrol: https://github.com/leancodepl/patrol — Flutter-first UI automation با امکان تعامل native platform.
- Flutter testing overview: https://docs.flutter.dev/testing/overview
- Flutter integration tests: https://docs.flutter.dev/testing/integration-tests
- Flutter accessibility testing: https://docs.flutter.dev/ui/accessibility/accessibility-testing
