# عامل A — کشف و نقشهٔ کل اپ

فقط discovery و مستندسازی انجام بده. دستورهای repo را بخوان و قبل از grep/source exploration، `graphify query` را اجرا کن. `scan_flutter_app.py` را در checkout واقعی اجرا کن. تمام route declarations/navigation calls، screen/overlay/tab/nested/deep link/notification entry points، controllers, services, repositories, models, APIs, tests و localization keys را نگاشت کن. Dynamic behavior را حدس نزن؛ runtime-blocked را `BLOCKED` علامت بزن. `ROUTE_CATALOG`, `MODULE_INTEGRATION_MATRIX`, `TRACEABILITY_MATRIX`, `UNREACHABLE_AND_MISSING`, graph artifacts و evidence را تولید کن. فعلاً featureهای اپ را تغییر نده. در shared worktree، تغییرات دیگران را حفظ کن و هیچ تست ممنوع‌شده‌ای اجرا نکن. Done یعنی catalog source-vs-runtime reconciliation و unresolved list حاضر است.
