# برنامهٔ اجرایی ۱۸۰ روزه UI/UX

## روز 1–5: Discovery
- baseline, routes, screenshots, owner, screen states, endpoints, test gap.
- benchmark 8 محصول/kit و انتخاب 3 flow pilot.

## روز 6–14: Foundation
- design tokens audit، component inventory، page-state standards، accessibility baseline.
- اصلاح Home/Wallet/Transfer Review/Receipt به‌عنوان pilot.

## روز 15–30: Critical money flows
- transfer, exchange, withdraw, cash-out, payment, gift, card creation, crypto deposit/withdraw.
- error/pending/retry/expired quote/insufficient funds/provider ineligible.

## روز 31–50: Accounts, cards, navigation
- accounts, cards, settings navigation, transaction history, search/filter, notifications.
- route audit و deep link behavior.

## روز 51–70: Auth, KYC, profile/support
- login, OTP, passcode, biometric, KYC, security, sessions, support tickets.

## روز 71–90: Accessibility/localization
- 6 locale, RTL/LTR, large type, semantic controls, contrast, screen reader.

## روز 91–120: Insights and instrumentation
- events privacy-safe، funnel/error recovery، performance profiling، dashboard analytics UX.

## روز 121–150: Usability validation
- moderated tests، task success/time/error rate، اصلاح navigation/copy/hierarchy.

## روز 151–180: Release-quality convergence
- all route inventory reconciled، golden suite، critical E2E، accessibility report، performance budget، release evidence.

## هر sprint باید تحویل دهد
- exact routes & files;
- design decision record;
- screenshots before/after;
- changed components and API state mapping;
- tests and analyzer output;
- risk list and rollback notes;
- evidence on exact commit.
