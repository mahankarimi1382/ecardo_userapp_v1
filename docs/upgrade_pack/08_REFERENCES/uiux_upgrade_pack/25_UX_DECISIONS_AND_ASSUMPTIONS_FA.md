# تصمیم‌ها و فرض‌های UX

1. منظور از XPay فعلاً UI Kit منتشرشده در AFGProgrammer است؛ اگر منظور محصول دیگری باشد، بنچمارک باید اضافه شود.
2. ۹۹ route عددی است که README مخزن اعلام می‌کند؛ نام دقیق routes باید از checkout جاری استخراج شود.
3. از GetX و design system فعلی استفاده می‌کنیم مگر اینکه issue تکنیکی و ADR تصمیم دیگری را اثبات کند.
4. UI kit تجاری صرفاً مرجع است؛ license پیش از استفادهٔ واقعی بررسی می‌شود.
5. UX باید با منبع حقیقت backend هماهنگ باشد؛ هیچ عملیات مالی با optimistic success قطعی نمایش داده نمی‌شود.
6. شش زبان موجود در گزارش پروژه: فارسی، عربی، انگلیسی، چینی، ترکی و روسی. این فهرست باید با ARBهای checkout تأیید شود.
7. برنامه ۱۸۰ روزه هدف برنامه‌ریزی است؛ estimate قطعی یا تضمین اجرا نیست.
8. packageها و repositories فقط candidates هستند؛ وضعیت maintenance/license/security در زمان adopt بازبینی شود.
9. تغییری در UI که روی flow مالی/امنیتی اثر دارد باید با owner backend/security بازبینی شود.
10. هیچ push/deploy/release ضمنی از روی این برنامه مجاز نیست.
