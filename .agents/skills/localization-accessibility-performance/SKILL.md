# چندزبانه، دسترس‌پذیری و performance

localeهای واقعی را از checkout تعیین کن. RTL، اعداد/ارز/تاریخ، text scaling، semantics/focus/touch targets/contrast/reduced motion را روی تمام page families تست کن. Performance با baseline/after در build/device مشخص سنجیده شود؛ بهینه‌سازی بی‌مدرک یا اضافه‌کردن dependency ممنوع.

## Required output
- Findings with severity, source evidence, SHA, owner and status.
- Updated catalog/traceability documents.
- Tests and exact command outcomes if this role is authorized to run them.
- Explicit blockers and unknowns; never infer complete coverage from a static scan alone.
